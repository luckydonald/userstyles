### Orion Browser (iOS/macOS)

- Download Stylus version 1.5.51 from https://addons.mozilla.org/en-US/firefox/addon/styl-us/versions/
  - (Probably https://addons.mozilla.org/firefox/downloads/file/4338993/styl_us-1.5.51.xpi, but that might change)
- Browse to this github
- Open the script you want
- Copy the URL after `@updateURL`, and paste it in the browser address bar
- Yes to install that userstyle
